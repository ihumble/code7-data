# Code 7 — daily player stats

`data.json` here is rebuilt every morning (3 am AEST) by GitHub Actions and downloaded by the Code 7 app when it opens.
Sources: ESPN (NBA, NFL schedules, rugby squads/results/tables), Sleeper (NFL stats), official Fantasy Premier League,
NRL Fantasy, Super Rugby Pacific Fantasy and Nations Championship Fantasy feeds. Sports stats only — no personal data.
Run it on demand: Actions → Daily stats refresh → Run workflow.
